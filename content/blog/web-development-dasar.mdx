Web development adalah salah satu skill paling produktif yang bisa dipelajari: hasilnya langsung terlihat, gratis dimulai, dan permintaannya terus tumbuh.

Artikel ini peta jalarannya — apa yang harus dipelajari berurutan, dan kenapa urutan itu penting.

## Tahap 1: HTML — Kerangka

HTML menentukan **struktur**: apa yang ada di halaman. Tidak ada logika di sini — hanya semantik.

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8" />
    <title>Halaman Pertamaku</title>
  </head>
  <body>
    <header>
      <h1>Selamat Datang</h1>
    </header>
    <main>
      <p>Ini paragraf pertama.</p>
    </main>
  </body>
</html>
```

Fokus di elemen semantik: `header`, `main`, `section`, `article`, `nav`, `footer` — bukan sekadar `div` di mana-mana.

## Tahap 2: CSS — Tampilan

CSS mengatur **penampilan**: warna, jarak, ukuran, dan tata letak. Setelah dasar, langsung pelajari:

- **Flexbox** — menyusun elemen satu arah (baris/kolom)
- **Grid** — tata letak dua dimensi
- **Responsive** — media query dan unit relatif (`rem`, `%`, `vw`)

Contoh grid tiga kolom yang otomatis menyesuaikan layar:

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 1rem;
}
```

Satu baris di atas = kartu menu di HP sampai desktop. Kekuatan CSS ada di kesederhanaan ini.

## Tahap 3: JavaScript — Perilaku

JavaScript membuat halaman **hidup**: klik, input, ambil data, update tampilan.

```js
// ambil data dari API dan render
const list = document.querySelector('#produk');
fetch('/api/produk')
  .then((res) => res.json())
  .then((items) => {
    list.innerHTML = items.map((p) => `<li>${p.name}</li>`).join('');
  });
```

Fokus pertama: variable, function, array/object, DOM manipulation, dan `fetch`. Setelah itu baru async/await dan konsep state.

## Tahap 4: Framework — Produktivitas

Setelah dasar JS terasa nyaman, saatnya framework. Saat ini jawaban paling umum: **React**, dan di atasnya **Next.js**.

Kenapa bukan langsung framework?

- Framework menyembunyikan DOM — tanpa memahami DOM, semua jadi magic.
- Debug error React tanpa dasar JS itu seperti perbaiki mesin tanpa tahu mesin.

Next.js (yang dipakai blog ini) menambah: routing file-based, server components, SEO, dan gambar optimasi di luar kotak.

Contoh komponen React sederhana:

```tsx
function ProdukCard({ nama, harga }: { nama: string; harga: number }) {
  return (
    <div className="card">
      <h3>{nama}</h3>
      <p>Rp {harga.toLocaleString('id-ID')}</p>
    </div>
  );
}
```

## Pola Pikir yang Membuat Cepat Mahir

1. **Bangun, jangan menonton.** Satu proyek kecil yang selesai > 10 jam tutorial.
2. **Baca dokumentasi resmi.** Tutorial usang cepat; dokumentasi adalah kebenaran.
3. **Sering refactor.** Tulis dulu yang berfungsi, lalu perbaiki strukturnya.
4. **Pelajari "kenapa".** Kenapa `const` bukan `let`? Kenapa server component? Ini yang membedakan developer dari pengetik kode.

## Sumber Latihan Pertama yang Bagus

Mulai dari yang nyata:

- Profil pribadi satu halaman (HTML + CSS)
- To-do list (JavaScript)
- Galeri foto dengan filter (React)
- Blog atau toko kecil (Next.js) — persis seperti yang ada di situs ini

## Kesimpulan

Urutan belajar web development selalu: HTML → CSS → JavaScript → framework. Jangan lompat. Situs ini sendiri hasil dari jalan itu: Next.js + React untuk tampilan modern, Tailwind untuk styling cepat — tapi fondasinya tetap struktur HTML yang benar dan logika JS yang bersih.
